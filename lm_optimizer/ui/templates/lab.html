Context Explorer, Quality Lab, Model Recommender and Duel — the workflows that are not the runtime optimizer. Local measurements always outrank community priors.

Model recommendations for this hardware

Fit is decided by file size and bits/weight — never by parameter count. A 27B at Q1_0 (4.4 GB) fits a 6 GB card; the same 27B at Q4_K_M (17.4 GB) does not.

Deterministic quality tasks

Hard gates run BEFORE scoring: an empty output, a failed schema or a missing function caps the score at zero — a broken answer never wins on appearance. Run them with lm-optimizer lab quality-lab <model>.
