Model recommendations for this hardware

Fit is decided by file size and bits/weight — never by parameter count. A 27B at Q1_0 (4.4 GB) fits a 6 GB card; the same 27B at Q4_K_M (17.4 GB) does not.

Deterministic quality tasks

Hard gates run BEFORE scoring: an empty output, a failed schema or a missing function caps the score at zero — a broken answer never wins on appearance. Run them with lm-optimizer lab quality-lab <model>.

Duel types

Controlled duels use identical context, sampling and seed for both sides; the blind judge only ever sees “Candidate A” and “Candidate B”. Run them with lm-optimizer lab duel <a> <b>.

Sandbox tasks

The model writes a solution into an isolated workdir; the acceptance criteria are checked automatically and a failed attempt gets evidence-only feedback for the repair loop. The artifacts land in results/sandbox/<task>/<timestamp>/ for you to inspect.

What the modes mean

                        
    
                            
  • Full campaign: speed discovery, quality suite,
                                recovery, final validation and the optional context phase.
    • 
                            
  • Speed only: S0 budget classification plus the
                                planned probes at a pinned context. No quality, no winner.
    • 
                            
  • Quality only: one quality suite on the baseline
                                config at the max context. No speed discovery.
    • 
                            
  • Reasoning only: the 5-level reasoning sweep
                                (off/low/medium/high/xhigh) on the baseline config.
    • 
                            
  • MTP only: S0 plus the speculative/MTP probes at a
                                pinned context, with an OFF baseline for the speedup ratio.
